## Step 1: Environment

1. Verify Python and package imports.
2. If Python fails, repair PATH or create a new virtual environment.
3. Record the exact runtime in `environment/environment_audit_20260810.md`.

## Step 2: Manifest Validation

1. Run `scripts/validate_manifest_consistency.py`.
2. Confirm Mojahid and TIGPR audited counts.
3. Compare current sample indexes against the unified schema.
4. Create missing fields by deterministic scripts only.

## Step 3: 4TU Coverage

1. Verify `manifest/4tu_project_index_v1.csv`.
2. Verify `manifest/4tu_project_file_map_v1.csv`.
3. Verify `reports/4tu_baseline_package_v1`.
4. Record which projects have raw traces and which only have rendered arrays.

## Step 4: Third Asset Gate

1. Review `manifest/ressam_external_checklist_v1.md`.
2. Determine whether Res-SAM has data, weights, script and environment access.
3. Use Res-SAM as the third local data asset for M0-M2 lightweight protocol work.
4. Keep full Res-SAM model replication gated until the SAM ViT-L checkpoint and compatible runtime are available.
5. Keep TIGPR as supporting evidence only until local source media are restored and the 7169-row sample index is rebuilt.

## Step 5: Minimum Baseline

2. Run HOG+RBF-SVM before CNNs.
3. Report grouped split performance before any random split.
