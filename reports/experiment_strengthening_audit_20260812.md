# 实验与结果补强全量审计

日期：2026-08-12  
目标期刊：*Nondestructive Testing and Evaluation*  
当前论文主张：数据来源、增广谱系和采集环境会使随机划分高估 GPR 识别模型的部署可靠性；来源隔离和跨环境评估会暴露这种脆弱性。

## 1. 总结论

1. 现有假设注册表中的本地实验已经完成并冻结，论文可以立即开始写。
2. 不能表述为“所有可能的实验都已完成”。目前最强的“独立外部泛化”主张仍缺真实盲法外部验证。
3. 对目标期刊而言，继续增加普通分类器、随机种子或公开非盲数据集的边际收益很低。最有价值的新证据依次是：真实盲法现场验证、端到端深度模型复现、GPR 物理采集扰动或原始道集验证。
4. 现阶段还有大量已经完成但尚未进入现稿的结果。先完成这些结果整合，比立即重开大规模实验更重要。
5. 推荐采用“有条件实验关闭”：现有公开/本地数据上的来源敏感性结论可以关闭；任何独立现场泛化或普适部署结论不得关闭。

## 4. P1：真正能显著提高论文上限的新实验

| ID | 新实验 | 设计要求 | 主要作用 | 成本 | 建议 |
| --- | --- | --- | --- | --- | --- |
| E01 | 真实盲法外部验证 | 第三方保管标签；模型、代码、阈值和分析计划先冻结；一次性解盲 | 唯一能关闭“独立外部泛化”硬缺口的实验 | 很高 | 最高优先级，有数据即解冻 |
| E02 | 独立现场工程验证 | 新场地或新结构；具有开挖、钻芯、施工记录或专家判读等物理真值 | 把公共数据集现象提升为 NDE 工程有效性证据 | 很高 | 与 E01 合并执行最佳 |
| E03 | 端到端深度模型复现 | ResNet18、EfficientNet-B0、DeiT-Tiny 等端到端训练；同一来源感知划分；至少 3 个种子 | 排除当前现象只是冻结嵌入或浅层分类器造成 | 高 | 无盲测数据时最值得补 |
| E04 | 原始道集语义模型 | 在 Zenodo 等原始 trace 上使用实际时空幅值，不使用文件元数据或字节签名作为主特征 | 回答“是不是只学到了文件格式，而没有学 GPR 信号” | 高 | 对目标期刊价值高 |

| E06 | 环境差异匹配与分解 | 匹配类别比例、样本量和处理流程，分别隔离环境、传感器、材料、仿真/实测因素 | 排除标签偏移和样本构成差异对 Res-SAM 结果的混淆 | 中至高 | 主数据元数据允许时强烈建议 |
| E07 | GPR 物理扰动鲁棒性 | time-zero 偏移、增益变化、带宽/中心频率变化、介电常数或速度误差、道缺失、背景杂波和噪声 | 将通用图像压力测试升级为与 GPR 采集物理相关的可靠性测试 | 中至高 | 推荐补一组受控实验 |
| E08 | 物理预处理迁移实验 | dewow、time-zero 校正、背景去除、增益归一化、频率匹配；全部参数仅由训练域决定 | 检验严格非转导、工程可执行的修复策略 | 中至高 | 原始道集可用时推荐 |
| E09 | 外部校准、拒识与 OOD 检测 | 校准集与测试域严格隔离；报告 ECE、Brier、NLL、AUROC、risk-coverage | 评价模型能否识别自己在新环境中不可靠 | 中 | 有外部域概率输出时推荐 |
| E10 | 重复采集的 repeatability/reproducibility | 同一目标跨日期、操作者、天线频率、增益设置重复测量 | 直接量化 NDE 测量系统的重复性和再现性 | 高 | 有现场采集条件时推荐 |
| E11 | 标签可靠性实验 | 双人或多人独立标注；报告一致性、仲裁规则和争议样本敏感性 | 排除标签噪声或专家分歧造成的伪域差异 | 高 | 新现场数据应同步执行 |

## 7. 推荐的最终补强组合

### 方案 A：不新增外部数据，尽快投稿

1. 完成 R01-R14 的主文/补充材料整合。
2. 完成 A01、A02、A04、A08、A11。
3. 计算资源允许时执行 E03。
4. 将论文结论严格限定为“公开/本地 GPR 数据上的来源感知评估揭示随机划分与跨环境可靠性风险”。
5. 明确声明没有真实盲法现场验证。

### 方案 B：追求明显更强的命中率和论文上限

1. 执行 E01+E02，形成一次预注册、一次解盲的独立现场验证。
2. 执行 E03，排除浅层或冻结特征解释。
3. 从 E04、E07、E08 中选择至少一项原始信号/物理机制实验。
4. 使用 A04 对现有和新增证据做统一分层统计。

## 8. 实验关闭判定

| 声明 | 当前是否可关闭 | 说明 |
| --- | --- | --- |
| 本地已注册实验已执行并冻结 | 是 | 冻结注册表 164 行，无缺失必需行 |
| 公开/本地数据上的来源敏感性现象 | 是，有边界 | 多资产、协议、模型和种子已有支持 |
| 随机划分可能高估 GPR 模型表现 | 是，有边界 | 统一矩阵 16 个对比中 15 个方向一致，但并非每个资产的每个协议都显著 |
| 该现象对端到端深度训练普遍成立 | 否 | 当前统一五家族矩阵不能替代端到端深模型训练 |
| 模型可泛化到独立新现场 | 否 | 缺真实盲法外部验证 |
| 已找到稳定、非转导的通用修复方法 | 否 | 现有修复效果依赖数据集，严格非转导修复尚无稳定收益 |
| 实验部分可以停止无限扩张 | 是 | 除 E01、E03 和一项物理信号实验外，其余新增训练边际收益有限 |

### 未闭合项

- A08 近重复审计已经补做完毕，不再是开放项。
- TIGPR 的 file-level pHash 扫描得到 246 组近重复碰撞、492 张碰撞图像，其中只有 3 组跨不同 file-hash group；这 3 组都仍是同标签、零汉明距离的重复对。
- 这说明现有 manifest 的精确重复信息仍是下界，但 TIGPR 里已经能确认一层额外的感知近重复结构。

最终建议：当前可以进入论文写作，但不要表述为“实验百分百无可补充”。若目标是尽快投 *Nondestructive Testing and Evaluation*，先完成现有结果整合和低成本统计补强，再根据资源决定是否只解冻 E03；若能获得真实独立现场数据，则优先解冻 E01+E02，其价值高于其他所有小实验之和。现阶段唯一仍然真正打开的高价值门槛是盲外部验证，其他可低成本补强项已经基本收口。
