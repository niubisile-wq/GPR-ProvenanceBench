# Release Notes

## v2026.08.13

Initial manuscript reproducibility release for Zenodo deposition.

This release includes:

- manuscript source and compiled submission PDF;
- manuscript figures and figure-generation script;
- dated experiment wrappers and analysis scripts;
- environment records;
- protocol notes;
- sample manifests and frozen split definitions;
- lightweight result summaries, source-data tables, and audit artifacts.

Raw third-party GPR data, model checkpoints, local caches, and bulky intermediate artifacts are not redistributed in this repository. They are excluded from the release package and should be obtained from original providers or requested from the corresponding author where appropriate.

Zenodo archive DOI: https://doi.org/10.5281/zenodo.21910757.
